# RabTech Academy Task 05 — Deep Learning / NLP Text Classifier

## Movie Review Sentiment Classifier using TensorFlow/Keras
This project demonstrates TF-IDF text vectorization, a multi-layer neural network, Batch Normalization, Dropout, Early Stopping, training/validation curves, held-out evaluation, and unseen-text predictions with confidence scores.

### Dataset
Keras IMDB movie-review sentiment dataset.

### Main deliverable
`deep-learning-nlp-sentiment.ipynb`

### Run
Open the notebook in Google Colab and select **Runtime → Run all**. Save the executed notebook back to GitHub so the mentor can see the curves and inference outputs.

The final cell also saves `sentiment_model.keras` and `tfidf_vectorizer.joblib`.

> Educational project: confidence is a model score, not a guarantee of correctness.
